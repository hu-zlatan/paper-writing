# 实验构想 · CertGrip（v1 草案，2026-11-08；第 9 阶段定稿并预注册，在此之前不跑任何主实验）

## 环境（MuJoCo，CPU）
- 平行夹爪（两指，指垫上离散 taxel 阵列，或 MuJoCo touch grid 传感器插件——第 10 阶段先验证其在 pip 版 MuJoCo 中可用）。
- 物体：盒体 / 圆柱 / 胶囊 / 凸多面体；采样质量、尺寸、摩擦系数 μ、质心偏移；抓取位姿给定（含随机偏离中心）。
- 扰动段（固定时长）：带加速度的提升、正弦摇晃、侧向拉力、附加载荷；每个抓取实例 = (物体, 抓取位姿, 扰动) 的一次采样。
- 打滑判定：物体相对指垫的平移 / 转动超过阈值（阈值在试点中定，写进预注册）。

## 标签：F* 的测量
- 同一实例、同一扰动，在 [F_min, F_max] 上二分握力（约 10 次重放），得到不打滑的最小力 F*。
- 先检验单调性：在试点实例上做细网格扫描，统计“更大力反而打滑”的比例；若不可忽略，改用共形风险控制处理非单调损失，并在论文中说明。

## 输入特征
- 接触建立后与试探挤压（短时小幅增力）期间的 taxel 压力分布统计、法向 / 切向合力、压力中心随时间的变化；
- 消融：(a) 只有物体无关的本体信号（夹爪位置 / 电流），(b) + 触觉，(c) + 试探挤压。

## 方法与基线
- CertGrip-split：预测器 g(x)（小 MLP / GBDT，第 9 阶段定）+ 分裂共形上界 F = g(x) + q̂ 或乘性版本 F = g(x)·exp(q̂)。
- CertGrip-online：在线自适应共形，更新只用二值打滑反馈。
- 基线：固定大力；名义 μ 的摩擦锥 × 安全系数（1.2/1.5/2.0，及在校准集上调到恰好满足 α 的系数——最强的公平对照）；点回归；
  未校准分位数回归；高斯 NLL 预测 σ 并取 z 分位；深度集成；Oracle F*（下界参考）。

## 数据划分与规模（试点后按实测耗时定稿）
- 训练 / 校准 / 测试 / 偏移测试 分别独立采样（不同随机盐）；校准集大小 n ∈ {100, 500, 2000}。
- 种子：预测器训练 ≥ 5 个种子；校准 / 测试重抽样 ≥ 100 次报告覆盖分布。
- 条件 ≥ 10：4 个 α × 物体族 / 扰动类型；偏移 3 类（新物体族、低摩擦、强扰动）。

## 指标
- 有效性：测试打滑率及其与 α 的有限样本区间（Beta 分布）；按物体组的条件覆盖。
- 效率：平均握力冗余 E[F − F*]、相对冗余、超过易碎阈值的比例。
- 偏移：在线打滑率随时间的曲线、长期平均与 α 的差。
- 计算：单次决策延迟（CPU）。

## 预算
- 试点（5 分钟）先估计每次重放耗时 → TIME_ESTIMATE → 定规模。预计主实验 < 100 CPU 小时，跑在免费 Actions 上（与第一篇共享并发）。
