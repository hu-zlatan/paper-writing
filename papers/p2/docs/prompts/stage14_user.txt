## 2. Validity route for H2 / H3: conformal risk control on the binary slip loss (07 H1-M failure branch)
- For an arm with predictor g and a calibration instance i, the force at level λ is F_i(λ) = min(F_max, g(x_i) e^λ);
  the loss is L_i(λ) = 1{slip in a direct replay at F_i(λ)} (physical outcome, not the label rule).
- **λ-grid (20 points, fixed per arm before calibration):** Λ_arm = q̂_sel + linspace(−0.4, 0.4, 20), where q̂_sel is the
  label-rule conformal quantile at α of the arm's scores on the **selection split** (objects 150–199), pooled over
  strata. The selection split is disjoint from cal and test.
- **Monotonised loss:** L̃_i(λ) = max over λ' ≥ λ in Λ of L_i(λ') (non-increasing in λ, L̃ ≥ L), so the risk-control
  guarantee for L̃ implies it for the physical slip loss.
- **CRC (per disturbance stratum, n = 500 calibration instances each):** λ̂ = the smallest λ ∈ Λ with
  (n R̃_n(λ) + 1)/(n + 1) ≤ α; if none, λ̂ = max Λ (reported). Guarantee: E[slip at λ̂] ≤ α for an exchangeable test
  instance.
- Replays: every calibration and test instance on the full grid (20 replays each) for the arms in §4, so bootstrap
  draws need no new simulation. Unavoidable instances count as slips at every λ.

## 3. Primary predictors, COMP selection, bootstrap
- **Seed:** the primary analysis uses the seed-0 predictor of every learned arm; seeds 1–4 are refit identically and
  D(H2a), D(H2b) are reported per seed (secondary; no decision depends on them).
- **COMP** (08b §3): candidates CSF-1, Mondrian-CSF, CertGrip-P (seed 0). On the selection split, objects with even
  index calibrate and odd index evaluate, then the roles swap; mean label-rule RE at α 0.10 over both halves; the
  smallest wins. Chosen and committed (`results/v1/comp_selection.json`) before any cal / test file is read.
- **H2a / H2b primary:** RE under the CRC route of §2 for both arms of each contrast (same λ-grid construction, same
  calibration draw), D = 1 − RE(CertGrip-full, σ 0.2) / RE(comparator). The label-rule conformal versions are reported
  as secondary (they were the pre-H1-M plan).
- **Bootstrap:** 2,000 object-cluster draws, resampling calibration objects and test objects within family (all four
  instances of an object move together); λ̂ (or q̂) is recomputed in each draw; percentile CI\*\* = 97.5 % two-sided

# p2 · Addendum 08d — H3 stream simulation, fixed before any stream result (run 40, 2026-11-09)

**Status:** written before any H3 stream, oracle-recalibration or stream-audit quantity has been computed. Only the
counts of labelled rows per pool / role were looked at (S1 / S1m / S3: 2,096 stream + 704 oracle instances each;
S2: 1,500 stream + 700 oracle). 07_hypotheses H3 / H3-x and 08b §5 stay authoritative; this file fixes the details they
leave open and records how the H1-M failure (08c §1) is handled for H3. Later changes go to a further dated addendum.

## 1. Arms and predictors
- CertGrip = full_rd, σ 0.2, seed 0 (`a010_full_rd_s0.2_seed0`); COMP = CSF-1 (`results/v1/comp_selection.json`).
- Online arms: OQT-CertGrip, OQT-COMP, decaying-step OQT-CertGrip (H3-S); Frozen-CertGrip, Frozen-COMP (offline q̂, never
  updated); Oracle-CertGrip, Oracle-COMP.
- **Trackers are per disturbance stratum** (decided here): one q per stratum, initialised at that stratum's offline
  label-rule q̂ (cal split, n = 500, α 0.10) and updated only on steps of that stratum. Reason: calibration is
  stratified (07 §1.4), so the pre-shift segment then behaves exactly like the offline method. The UT4 identity holds per
  tracker.
- **η** = 0.1 × IQR of the in-distribution calibration scores of CertGrip (label rule, all strata pooled), computed once
  and used for every tracker (07 §1.4). Anti-windup: no update on a step whose force was capped at F_max.
- **Oracle**: label-rule split conformal at α per stratum on the shift pool's oracle objects (S1 / S1m / S3: id objects
  325–368 per family, shifted versions; S2: s2 objects 0–174); used for every post-shift step; pre-shift steps use the
  offline q̂.

## 2. Streams
- T = 2,000; steps 1–500 in-distribution, 501–2,000 shifted. Pre-shift steps: 500 drawn without replacement from the
  unshifted id instances of objects 325–368 (704 instances; for S2 the same set). Shifted steps: 1,500 drawn without
  replacement from the shift pool's stream instances (S1 / S1m / S3: 2,096 instances of objects 369–499; S2: all 1,500,
  i.e. a permutation). Steps are shuffled within each segment.
- 20 orderings per shift (`numpy.random.default_rng([4242, shift index, ordering])`).
- ρ_ID for H3-L: an unshifted stream built the same way, with the 1,500 "shifted" steps drawn from the unshifted id
  instances of objects 369–499.
- Window = steps 1,001–2,000. RE_window = mean over window steps of (F_t − F\*_mid)/F\*_mid on avoidable instances.

## 3. Feedback and the H1-M failure
- **Simulated feedback = label rule** slip_t = 1{F_t < F\*_hi,t}, as designed in 07 ("cheap because it replays labels");
  unavoidable instances give slip_t = 1 at every force (they update the tracker like any slip when the force is below
  F_max; corrected in the same run before any stream result, the first wording wrongly said they never update). This is what makes the 20
  orderings and the regenerated-ordering bootstrap affordable.
- Because H1 is not confirmed (8 / 800 non-monotone flickers just above F\*), the label rule is not the physical
  outcome. Two direct-replay audits (protocol rd, ordering 0 only) measure the difference:
  (a) the pre-registered audit: OQT-CertGrip and OQT-COMP, steps 501–1,000, every shift (4 × 2 × 500 replays);
  (b) added here for 08c §3: OQT-CertGrip and Oracle-CertGrip over the whole window 1,001–2,000, S1 / S2 / S3
  (3 × 2 × 1,000 replays). The matched-rate co-requirement uses the realised **physical** slip rates of (b) (point
  difference ≤ 0.02); label-rule window rates (20 orderings) are reported next to them. The paired disagreement
  Δ = mean(slip_direct − slip_label) is reported per audit with an object-cluster bootstrap CI.
- The force schedules of ordering 0 depend only on labels and the tracker rule, so they are written first
  (`results/v1/h3/schedule_<shift>.json`) and replayed by `main.py replay` jobs; the analysis then joins them.

## 4. Inference and decisions (unchanged from 07 / 08b, restated)
- R_E(s) = RE_window(OQT-CertGrip) / RE_window(Oracle-CertGrip), averaged over the 20 orderings (ratio of the averaged
  RE_windows). CI\*\* (97.5 %) from 2,000 object-cluster bootstrap draws that resample, within family, the stream
  objects and the oracle objects (the pre-shift instances belong to the oracle objects and move with them), then
  regenerate the 20 orderings and refit the oracle q̂. The offline q̂ and η are held fixed (they come from the cal split,
  which is not resampled here).
- H3 passes iff the CI\*\* upper limit of R_E(s) < 1.10 for S1, S2 and S3 and the matched-rate co-requirement holds;
  failure per shift iff the lower limit > 1.10; otherwise inconclusive (08b §5: reduced power stated up front).
- Secondary (H3-B, H3-L, H3-S, Frozen arms, capped-step counts) computed from the same streams.

## 5. Order of work
1. `h3_streams.py` (stream generator, per-stratum OQT, oracle, frozen; bootstrap) + synthetic tests → commit.
2. Write the ordering-0 schedules only (no metric printed) → `main.py replay` manifest → Actions.
3. Run the label-rule read-out and the audit join once → `results/v1/h3_analysis.json`.

# p2 · Addendum 08e — CRC grid sensitivity (post hoc, run 40, 2026-11-09)

**Status:** written **after** the 08c CRC read-out (`results/v1/crc_analysis.json`) and the label-rule secondary
(`results/v1/h2_label_rule.json`) were seen, and before any replay of this addendum exists. It is a **post hoc
sensitivity analysis**; it does not replace the pre-registered 08c decisions, which stand as computed and are reported
with the defect below.

**Defect.** 08c centred each arm's 20-point grid on the pooled selection q̂ (±0.4). For the physics plug-ins the
per-stratum CRC solution in D1 / D2 lies at or below the grid floor (λ̂ index 0 for CSF-μ̂ at σ ≤ 0.2, index 1 for CSF-1),
so those arms over-protect and their RE is inflated; the CRC-route D(H2b) is biased towards CertGrip.

**Sensitivity design.** Per-stratum grids Λ_arm,d = q̂_sel,d + linspace(−0.8, 0.8, 41), q̂_sel,d the label-rule conformal
quantile at α of the arm's scores on the selection split within stratum d (objects 150–199; no cal / test data).
Arms: CertGrip-full seed 0 at σ 0 / 0.1 / 0.2 / 0.4, CSF-1, CSF-μ̂ at the four σ, onset-only σ 0.2.
Grids: `results/v1/crc_grids_v2.json` (`python crc_grids.py --v2`); replays `main.py crc --grids crc_grids_v2.json`
→ `results/v1/crc_v2/`; read-out `python analysis_crc.py --v2` → `results/v1/crc_analysis_v2.json`, the same CRC rule,
bootstrap and decision code as 08c. A floor- or ceiling-bound λ̂ is reported per arm and stratum.

**Reporting rule (fixed now).** The paper reports the 08c CRC decisions as pre-registered, the label-rule route, and this
sensitivity side by side. If the sensitivity changes a decision, the paper says so and treats the pre-registered CRC
result for that contrast as unreliable because of the grid defect; no decision is upgraded on the strength of a post
hoc analysis alone.

# p2 · Addendum 08f — operational choices for the remaining secondaries (run 42, 2026-11-09)

**Status:** written before any quantity below has been computed. Already seen at this point: the H1-M, H1-V, H2 (CRC
08c, CRC 08e, label route), H3 / H3-L and H4a read-outs. Nothing here is new data collection: H4c and H2-M need new
predictor fits on the id **train** objects (labels already exist); everything else reuses existing labels, predictors
and CRC replays. 07_hypotheses §4 / 08b §6 left the operational details below open; they are fixed here. Every item is
secondary or a diagnostic; no primary decision depends on it. CI\*\* = 1.25 / 98.75 percentile, 2,000 object-cluster
draws (cal and test objects resampled within family, q̂ / λ̂ refitted per draw), as in 08c / h4a, unless stated.
Holm is not applied to the CI\*\* rules here; each result is reported with its interval and labelled secondary.

## 1. H2-T (tail non-inferiority, 07 §4)
- Metric: P95 of the per-instance relative excess (F − F\*_mid)/F\*_mid over avoidable id test instances;
  T = P95(CertGrip-full σ 0.2) / P95(COMP = CSF-1).
- Routes: **CRC 08c grids (primary route of 08c)**, CRC 08e grids and the label rule — all three reported.
- Rule (07): pass iff CI\*\* upper < 1.10; failure iff CI\*\* lower > 1.10; else inconclusive.

## 2. H4c (shuffled-touch control)
- Arm `full_rd_shuf` (σ 0.2): the CertGrip-full feature vector in which every non-P column (static touch, preload-slip
  flag, squeeze-probe and onset features — 08b §6 "shuffles the probe features as well") is permuted across rows within
  each (pool, shift, split, disturbance) group with a fixed seed derived from the group name; the P columns (disturbance
  one-hot, commanded acceleration, log mass, aperture) stay with their row. Same 30-config search, seed 0, α 0.10,
  `main.py fit --fset full_rd_shuf`.
- Contrast, label route (08c: arms outside the CRC set use the label rule): D = 1 − RE(shuf)/RE(CertGrip-P seed 0).
- Rule (07): equivalence (pass) iff CI\*\* inside ±0.05; failure iff CI\*\* lower > 0.05 (shuffled beats P by > 5 %);
  else inconclusive.

## 3. H2-M (no-mass condition only)
- Fits with `--no-mass` (log mass removed from the base features): CertGrip-P and CertGrip-full σ 0.2, seed 0.
- COMP re-selected: CSF-1 and Mondrian-CSF need the mass, so the only non-tactile candidate is CertGrip-P (no mass);
  no selection-split run is needed. D_nm = 1 − RE(full_rd, no mass)/RE(P, no mass), label route; reported next to the
  with-mass label-route D(full_rd vs P) on the same draws. No directional prediction (07).
- The 10 % mass-noise condition is **not run in this batch** (its noise draw was never specified); if it is run later
  its draw is fixed in a further addendum first.

## 4. H3-B (offline breakage magnitude)
- Arms (08b §6: the location prediction applies to no-probe arms): CertGrip-P, CertGrip-S, CertGrip-full (squeeze, no
  onset), CSF-1, all seed 0 / formula. The onset arm (full_rd σ 0.2) gets p_obs only: 08b promised "separate in /
  out-of-support predictions" but never specified them, so no test is run for it (stated as a deviation).
- Per stratum d: q̂_d from the id cal split (label rule, n = 500); p_obs = mean 1{F < F\*_hi} over the shift pool's
  test instances (all id test objects 325–499; unavoidable instances count as slips), F = min(F_max, g e^{q̂_d});
  p_pred = 1 − F̂_ID,d(q̂_d − Δ), F̂_ID,d the empirical CDF of the unshifted id test scores of the same objects;
  pooled over strata by instance counts. Δ = 0.511 (S1), 0.105 (S1m). Rule: pass iff CI\*\* of p_obs − p_pred inside
  ±0.02; failure iff CI\*\* excludes ±0.02 entirely; else inconclusive.
- S3: p_obs with CI\*\* (predicted direction up). S2 (pool s2, F5; all stream + oracle instances): break iff
  CI\*\* of p_obs − α excludes ±0.05.

## 5. D-μ (diagnostic)
- Residual r = log F\*_hi − log g per arm on the 4,800 id cal + test instances (out-of-sample for every predictor; the
  07 wording "train objects" is not used because the train rows are in-sample fits — stated as a deviation). CV R² of a
  linear fit log μ → r, 5-fold GroupKFold by object (the pilot's `cv_r2`), point estimate plus a 500-draw
  object-cluster bootstrap 95 % interval. Arms: P, S, full, full_rd σ 0 / 0.1 / 0.2 / 0.4, P_onset σ 0.2, CSF-1,
  CSF-μ̂ σ 0 / 0.1 / 0.2 / 0.4, oracle. Interpretive threshold R² ≤ 0.05 (no-probe arms only, 08b §6).

## 6. UT3 (label-rule split-conformal unit test)
- Pool: the 1,200 id cal + test objects (4 instances each, one per stratum). 1,000 uniformly random object-level
  re-splits (seed 3) into n calibration objects and the rest as test, n ∈ {50, 500}; per stratum q̂ at α ∈ {0.01, 0.05,
  0.10, 0.20}; methods P, S, full, full_rd σ 0.2, CSF-1 → K = 160 cells. Miss = label slip rate on the test objects.
- Pass per cell iff the mean miss over re-splits lies in [α − 1/(n+1) − z·SE, α + z·SE], z = Φ⁻¹(1 − 0.05/(2K)),
  SE = SD/√1000. Report: number of passing cells, worst cell, and the re-split SD (descriptive).
