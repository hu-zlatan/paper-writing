## 本日已打开核对过的最相近工作（arXiv 摘要页）
- arXiv 2607.25049 — FIRMGrasp: A Friction-Informed Risk Margin for Robust Grasp Synthesis（Enwerem, Baras, Belta）。
  把摩擦系数当随机变量、取 CVaR 得到风险调整后的力闭合裕度；保证依赖假定的摩擦先验，离线抓取综合，无触觉输入。
  区别：我们在线从触觉选力，保证与分布无关（不需要摩擦先验）。
- arXiv 2411.07833 — Robust Adaptive Safe Robotic Grasping with Tactile Sensing（Kim, Kim, Li, Ames, Sloth）。
  控制障碍函数约束接触力与力闭合，触觉估计接触；保证在有界扰动 / 参数不确定性假设下成立，非概率。
  区别：我们给的是打滑概率保证，且不需要扰动界。
- arXiv 2605.23568 — TactileReflex（Feng 等）。视触觉传感器上的反射式防滑 / 护力控制，阈值取静态保持噪声的百分位，实机实验，无概率保证。
- arXiv 2608.09166 — Particle-Based Conformal Prediction for Contact-Aware Uncertainty Calibration in Stratified
  Configuration Spaces（Marques, Popov, Berenson；PMLR 329, 2026）。接触感知的共形预测区域用于 MPC 运动规划；不涉及握力 / 打滑。
  区别：说明共形预测已进入接触丰富的机器人问题，但握力选择这一环还没有人做。
- arXiv 2505.18472 — ManiFeel（视触觉策略学习基准）；arXiv 2601.10268 — 触觉传感器配置对抓取学习效率的影响（仿真对比）。
  这类“触觉有没有用”的研究与本文的触觉消融相关，但不涉及失败率保证。

## 审稿人可能的问题（需要在论文里防御）
1. 只在仿真：MuJoCo 软接触的打滑与真实摩擦差距大 → 明确只主张“校准机制的有效性”，保证不依赖仿真逼真度，但 F* 预测器
   的效率依赖它；给出实机所需的接口（在线变体只需二值打滑反馈）。
2. 可交换性在实机不成立 → 在线变体 + 偏移实验。
3. 在校准集上调安全系数也能满足 α → 这是最强基线，必须纳入；论文的增益只能来自“按实例的触觉自适应”带来的更小冗余。
4. 条件覆盖：平均满足 α 但某些物体组严重违约 → 报告分组覆盖，必要时用 Mondrian（按组）共形。
5. F* 的单调性与二分测量的可靠性 → 试点中检验并报告。
6. 与第一篇的关系：完全不同的问题与代码路径，无共享结果或文字（AUTOPILOT §7）。
