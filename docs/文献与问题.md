## 审稿人可能提出的问题与防御

| # | 可能的质疑 | 防御 / 需要的证据 |
|---|---|---|
| Q1 | 这只是把 DAD / RL-BED 换了个应用，新意不足。 | 触觉定位的特殊性：不可微接触、负信息、离散身份 × 连续位姿的混合多峰后验、物理接触与几何模型的迁移。必须用消融证明这些处理是必要的（A1、A2、A3）。 |
| Q2 | 贪心 EIG 已经很好了，非短视有多大用？ | E1 + A1 直接回答；若差距只在低预算出现，如实报告并解释（子模性给出的贪心保证，Javdani 2013）。 |
| Q3 | 基线是否调到最强？ | Greedy-EIG 的粒子数、候选数在相同 CPU 预算下做网格调参，报告调参过程；同时给出"不限计算"的 Greedy-EIG 上界。 |
| Q4 | 只有仿真，没有真实机器人。 | 明确写在局限性中；用 MuJoCo 物理接触与噪声 / 先验错配实验部分补偿；RSS 两阶段制下 Stage 2 若主人有硬件可补。 |
| Q5 | 只做 SE(2)，太简单。 | 视进度扩展到部分 SE(3)；在讨论中分析维度增加时的代价与方法的可扩展性（策略延迟与维度无关，粒子滤波随维度指数增长）。 |
| Q6 | sPCE 下界在 L 较小时偏松，训练目标是否可信？ | A4 报告 L 的影响；评价时用大 L 的估计 + 精确网格后验（小问题）交叉验证。 |
| Q7 | 已知形状库的假设太强。 | 局限性中说明；讨论与形状估计方法结合的路径。 |
| Q8 | 统计显著性？ | 共用测试场景的配对检验 + bootstrap CI，代码里实现并在 results/ 中保存检验输出。 |
