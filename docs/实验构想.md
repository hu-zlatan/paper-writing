# 实验构想（v1，2026-10-28，第 1 阶段撰写；第 9 阶段据此生成 docs/08_experiment_plan.yaml，之后随循环版本化）

所有数字只能来自 `code/` 的真实运行，写入 `results/`。每个扫描先跑 1 个条件的 pilot 并打印 `TIME_ESTIMATE`；所有长脚本带 time_guard；所有训练 / 迭代带真实收敛判据。

## E0 环境与观测模型校验
- 几何探针模型：射线-多边形（SE(2)）求交的单元测试（解析可验证的正方形 / 圆 / 三角形）。
- 粒子滤波：在固定触碰序列下，后验均值误差随触碰数下降；与网格穷举后验（小问题上可精确计算）对比，验证滤波器正确性（KL 或 TV 距离）。
- MuJoCo 物理接触：指尖（小球）沿设计直线以位置控制推进，直到 touch / contact 传感器触发，记录接触点；与几何探针模型给出的接触点比较，得到两种保真度之间的差异分布。

## E1 主实验：选点策略对比
- 物体集合（至少 3 组）：O1 = 6 个凸多边形；O2 = 含对称与近似对称形状的 8 个形状（诱导多峰后验）；O3 = 非凸形状（L 形、T 形、星形等）。
- 传感器噪声 σ ∈ {1, 3, 5} mm（接触点），先验位置范围与角度范围固定。
- 触碰预算 T ∈ {3, 5, 8, 10}。
- 方法：
  - Random：在设计空间均匀采样。
  - Coverage：按角度均匀环绕的确定性启发式。
  - Greedy-EIG（粒子滤波 + 嵌套 MC 估计一步 EIG，在 M 个候选设计里取最大；M 与粒子数做调参以保证是强基线）。
  - Greedy-EIG-fast（减少粒子 / 候选，与我们的方法对齐延迟时的表现）。
  - TouchBED（我们的方法，非短视）。
- 指标：平移误差（mm）、旋转误差（deg，考虑对称性的最小等价误差）、身份准确率、成功率（< 5 mm 且 < 5°，并给阈值曲线）、后验熵、sPCE 估计、单步决策延迟（ms，CPU，同一机器）。
- 种子：≥ 5 个训练种子 × 每个种子 ≥ 200 个测试场景（同一测试场景集合供所有方法共用，做配对检验）。
- 统计：配对 Wilcoxon 符号秩检验 + bootstrap 95% 置信区间，代码中实现后才能在论文中写。

## E2 消融（每个"有效组件"一行）
- A1 非短视 → 短视：同一网络以一步 EIG（T=1 的 sPCE）为目标训练。
- A2 去掉负信息：训练和推理时把"未接触"观测当作无信息（策略输入中屏蔽）。
- A3 历史编码器：DeepSets → 只看最近一次触碰 / 无历史（固定开环序列，即静态设计优化）。
- A4 对比样本数 L ∈ {16, 64, 256}：训练目标的偏差 / 方差权衡。
- A5 设计空间参数化：起点 + 方向 vs 仅方向（朝工作区中心）。

## E3 迁移与鲁棒性
- 在几何模型上训练的策略，用 MuJoCo 物理接触评估（同一测试场景），报告与几何评估的差距。
- 训练时噪声与测试时噪声不匹配（训练 σ=3 mm，测试 σ=1/5 mm）。
- 物体位姿先验范围外推（测试先验比训练先验更宽）。

## E4 计算代价
- 单步决策延迟、训练总 CPU 时间、内存；Greedy-EIG 的延迟随粒子数 / 候选数的缩放曲线，与 TouchBED 的常数延迟对比。

## 条件数估计
E1：3 物体集合 × 3 噪声 × 4 预算 × 5 方法 = 180 组评估条件（策略训练只按物体集合 × 噪声训练，预算可在同一 T_max 策略上截断评估，另训练少数 T 专用策略验证）；E2：5 个消融 × 2 物体集合；E3：≥ 6 组。总计远超 MEGA_PROMPT 要求的 10–15 组条件。按 RESTRICTS 缩放规则，条件 > 100 时种子数取 3–5。

## 算力预期
- 几何模型每次触碰模拟为向量化求交，单场景 T=10 应在毫秒级；策略网络为 < 100k 参数的 MLP，CPU 训练。若 pilot 显示总时长超预算，先缩小粒子数 / 训练步数，再把长扫描放到 GitHub Actions。
- 只有当 CPU 上确实做不扎实时才在 OWNER_TODO.md 提 GPU 需求。
